6468(context,index,value) is a general DWORD register writer:
- Save value argument R8D; byte_offset=(uint32(index)<<2) modulo2^32 at647e.
- Compare offset with context DWORD+90 at6484. If below, call62e8 at64a6
  with PCI I/O pointer context+20, BAR byte context+104, offset, saved value.
- Otherwise test byte_offset bit31 at64bd. Set -> index/data ports0/4;
  clear -> index/data ports30/34, all offsets within the same selected BAR.
- Index value sent is byte_offset. Code reads index port after writing it,
  writes saved value to data port, then reads index port again.
62e8 checks protocol pointer, forces Width=Uint32(2),Count=1, and invokes
Mem.Write at6316. No CC-specific check is present in these helper bodies.
The threshold is routing selection, not a rejection of larger offsets.
Companion6320 performs the corresponding read routes.
